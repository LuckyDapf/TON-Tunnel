# Участие в проекте

1. Сделайте **fork** репозитория и ответвление от ветки `main`.
2. Держите PR **узкими** по смыслу: по возможности один логический смысл изменения на один pull request.
3. Придерживайтесь стиля существующего кода (Kotlin на Android; **C++20** в нативной части).
4. Изменения в `third_party/ton` оформляйте **похожими на апстрим патчами**, чтобы затем можно было частично накладывать обновления вендора.
5. Не добавляйте в git каталоги `build/`, `.gradle/` и автогенерируемые файлы — см. [`.gitignore`](.gitignore).
6. При изменении поведения, видимого снаружи, или формата сообщений по протоколу обновите [`BUILD.md`](BUILD.md) и/или [`PROTOCOL.md`](PROTOCOL.md).

## Лицензия вклада

Отправляя pull request, вы подтверждаете, что ваш вклад может распространяться на условиях **AGPL-3.0** в той же редакции, что и файл [`LICENSE`](LICENSE). Если вы вставили фрагменты из других проектов, явно укажите источник и лицензию в описании PR или комментариях.
