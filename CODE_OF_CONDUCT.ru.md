# Кодекс поведения участников

**TON Tunnel (DapfTON)** придерживается **Contributor Covenant 2.1**.

## Куда смотреть

- Авторитетный текст на **английском**: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
- Переводы на другие языки (в т. ч. русский интерпретационный текст): официальный список [contributor-covenant.org/translations](https://www.contributor-covenant.org/translations).

Юридически при конфликте формулировок применяется **англоязычная версия** в `CODE_OF_CONDUCT.md`, привязанная к тексту версии 2.1 на сайте Contributor Covenant.

## Сообщить о нарушении / Report

Об оскорбительном или запрещённом поведении сообщайте через **канал связи, указанный в профиле владельца репозитория на GitHub**, либо согласно правилам, которые мейнтейнеры публикуют в Issues / Discussions.

На **уязвимости безопасности** (CVE-уровень, утечка трафика, RCE и т. п.) действует процедура из [`SECURITY.md`](SECURITY.md) / [`SECURITY.ru.md`](SECURITY.ru.md) — **не смешивайте** её с жалобами по кодексу.

## Кратко о стандарте

Участники обязаны:

- сохранять уважительное общение;
- не использовать домогательства, преследования, разжигание ненависти;
- не публиковать чужую личную информацию без согласия.

Мейнтейнеры вправе модерировать issues, коммиты и PR в соответствии с текстом кодекса на английском.
